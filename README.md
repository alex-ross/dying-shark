# Dying Shark

A Flappy Bird-inspired game where you control a great white shark through underwater obstacles!

## Game Rules

- Control the shark by pressing SPACE, clicking, or tapping the screen
- Avoid crashing into coral reefs and rock formations
- Score points by swimming through obstacles
- The game gets harder the further you progress

## Controls

- **Desktop**: SPACE or mouse click
- **Mobile**: Tap the screen
- **Audio**: Click the sound icon to mute/unmute

## Features

- Responsive design that works on both desktop and mobile
- Progressive difficulty
- High score saved locally
- Sound effects and background music
- Minimalist pixel art graphics

## Technical Information

The game is built with:

- HTML5 Canvas for rendering
- Vanilla JavaScript for game logic
- Web Audio API for sound
- CSS for responsive design

## Installation

### As web app (recommended)
1. Visit the [GitHub Pages site](https://alex-ross.github.io/dying-shark)
2. On iPhone: Tap "Share" → "Add to Home Screen"
3. On Android: Tap menu → "Add to Home Screen"

### Locally
1. Download all files
2. Open `index.html` in a browser
3. Play!

## PWA Features

- **Installable** - Add as app to home screen
- **Offline support** - Works even without internet connection
- **Fast loading** - Cached for better performance
- **Fullscreen mode** - Play like a real app
